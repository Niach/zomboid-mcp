# Zomboid MCP — "Claude hacks the simulation"

## Goal
One proper mod that exposes as much of Project Zomboid's engine as possible to Claude through MCP, so anything the
owner comes up with (giant snail, bananas from the sky, a rolling 3D Claude star, a flappy bird on screen, a merchant
zombie …) can be made to happen live on the server, with good docs and a skill. Easy install: the MCP server ships
**inside the mod**, is pure Python stdlib, and needs one `claude mcp add` line. Workshop item **3810456179**, title
"Zomboid MCP", **public**.

bind-mounted from `/opt/zomboid-lua/ZomboidMCP` for hot reload during development (ZOM-9 sets up the mount).

## Protocol (details in docs/PROTOCOL.md)
- **Requests:** MCP → `zmcp_req_<n>.json`, numbered by the server's `nextReq`; the server executes in order on each
  tick and answers with `zmcp_res_<n>.json` (newline-terminated). At-most-once, gap probing, stale refusal.
- **Heartbeat:** `zmcp_status.json` every 2 s: players, time, paused, tools, scripts, bootId.
- **Events:** `zmcp_events.log`, one JSON object per line; the MCP exposes it as `events_poll`.
- **Paused server:** with `PauseEmpty=true` no Lua event fires while nobody is online; the MCP wakes the bridge with
  `reloadlua ZomboidMCP/ZMCPPoll.lua` through the console FIFO when it has console access.
- **Large arguments:** strings above 32 kB travel as `zmcp_blob_*` files (`<key>_file`), read with `ZMCP.argText`.
- **Client:** `sendServerCommand("zmcp", cmd, args)`; chunked code/base64, hello + resend for late joiners.
