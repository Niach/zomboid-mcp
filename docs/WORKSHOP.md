[h1]Zomboid MCP: let Claude script your running Project Zomboid world[/h1]
Ask Claude (or any other MCP client) for something, and it writes the Lua and runs it in your game or server, live, without a restart.

[h2]What it does[/h2]
[list]
[*][b]World queries[/b]: players, health, skills, inventories, and the zombies, objects and vehicles around any loaded tile, plus a searchable index of the engine Lua API.
[*][b]Building and tiles[/b]: place and remove tile objects, build walls and floors, add invisible collision, spawn items, vehicles and zombies, change weather and time.
[*][b]Runtime 3D models and entities[/b]: upload a mesh and a texture while the game runs, place it with collision, or fly it around as a moving 3D entity.
[*][b]Scenes, cutscenes and mini-games[/b]: scripted scenes with zombie puppets, lights, sounds and triggers. Examples ship with the mod: Flappy Bird on an in-game phone, a haunted house, and "You shall not pass", a lava cavern with a stone bridge, a wizard, a demon and a cutscene.
[*][b]Scripting that persists[/b]: run Lua on the server or on players' clients; installed scripts and persistent scenes come back after a restart and are sent to players who join later.
[/list]

[img]https://raw.githubusercontent.com/Niach/zomboid-mcp/main/art/showcase/flappy_phone.jpg[/img]

[h2]How it works[/h2]
The mod contains a small server-side bridge that watches the game's own Lua folder (Zomboid/Lua) for request files, runs each request on the next server tick and writes the answer back as a file. The MCP server, one Python 3 script with no dependencies, turns MCP tool calls into those files, locally or on a remote server over ssh. The mod opens no network port. Anything drawn on a player's screen is forwarded from the server to the client mod through the game's normal server commands, so every player sees it, including late joiners.

[h2]Install[/h2]
[olist]
[*]Subscribe to this item. For single player or a hosted game, enable [b]Zomboid MCP[/b] in the mod list.
[*]On a dedicated server, add it to the server ini: the Workshop id to [b]WorkshopItems=[/b] and the mod id to [b]Mods=[/b] (Build 42 writes it as [b]\ZomboidMCP[/b]).
[*]Get the MCP server from the GitHub repo (it also ships inside the mod folder as mcp/zomboid_mcp.py) and register it with Claude Code or any MCP client:
[code]claude mcp add zomboid -- python3 /path/to/ZomboidMCP/mcp/zomboid_mcp.py[/code]
A local game is found automatically (~/Zomboid/Lua). For a remote server add --ssh user@host --lua-dir <the server's Zomboid/Lua>. The mcp/install.sh script does the registration and also installs the "zomboid engine" handbook skill for Claude.
[/olist]
